تعديل إشعار حد العملاء/المستخدمين وطلب التجديد عبر واتساب

ما الذي تم تعديله؟
- عند وصول المستخدم إلى الحد المسموح في الاشتراك، لا تظهر رسالة OK فقط.
- تظهر رسالة بعنوان: تجديد الاشتراك مطلوب.
- الرسالة توضح أن المستخدم بلغ الحد الأقصى.
- يظهر رقم مسؤول التجديد داخل الرسالة إذا كان مضبوطًا في app.json.
- يوجد زران: اشتراك شهري واشتراك سنوي.
- عند الضغط على أحد الأزرار يفتح واتساب برسالة جاهزة إلى رقم مسؤول الاشتراكات.
- الرسالة الجاهزة تحتوي بيانات المستخدم ورقم الحساب ومعرف المستخدم والاستخدام الحالي إن توفر.

مهم جدًا: ضبط رقم مسؤول الاشتراكات
افتح ملف app.json وابحث عن:
EXPO_PUBLIC_ADMIN_WHATSAPP_NUMBER

ضع الرقم بصيغة دولية بدون + وبدون مسافات، مثال تركيا:
905555555555

مثال:
"EXPO_PUBLIC_ADMIN_WHATSAPP_NUMBER": "905555555555"

بعد تغيير الرقم شغل التطبيق بتنظيف الكاش:
npx expo start -c

طريقة التجربة:
1- من الداشبورد اجعل حد المستخدم 1 أو 2 فقط، أو ألغِ اشتراكه ليعود للحد المجاني.
2- ادخل التطبيق بنفس المستخدم.
3- أضف عملاء حتى يصل إلى الحد.
4- حاول إضافة عميل أو ربط مستخدم جديد.
5- تظهر رسالة تجديد الاشتراك مطلوب.
6- اضغط اشتراك شهري أو اشتراك سنوي.
7- يفتح واتساب برسالة جاهزة لمسؤول التجديد.
8- بعد الدفع أو الموافقة، يقوم الأدمن بتفعيل الاشتراك من الداشبورد.
