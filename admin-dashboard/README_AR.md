# لوحة تحكم ArtiCodeApp المستقلة

هذه لوحة تحكم ويب مستقلة تعمل من المتصفح، وليست جزءًا من تطبيق Expo/React Native. تم تجهيزها لتقرأ البيانات الحقيقية من نفس قاعدة بيانات Supabase الخاصة بتطبيق ArtiCodeApp.

## ماذا تعرض اللوحة؟

- إجمالي المستخدمين من جدول `app_security`.
- المستخدمون النشطون وآخر دخول لكل مستخدم.
- الاشتراكات الشهرية والسنوية.
- تاريخ بداية ونهاية الاشتراك.
- الاشتراكات القريبة من الانتهاء والمنتهية.
- المدفوعات والفواتير.
- حركة الحساب لكل مستخدم بشكل منفصل، وتشمل:
  - دخول المستخدم.
  - محاولات الدخول.
  - الحركات المالية المرتبطة بالمستخدم من `account_movements`.
  - إنشاء/تعديل الاشتراكات.
  - تسجيل المدفوعات.

## خطوات التشغيل

### 1) شغل ملف SQL في Supabase

افتح Supabase Dashboard ثم SQL Editor، وشغل الملف التالي الموجود داخل المشروع:

```txt
supabase/migrations/20260501000000_admin_dashboard_subscriptions.sql
```

هذا الملف ينشئ:

- `admin_subscriptions`
- `admin_payments`
- `admin_activity_logs`
- `admin_dashboard_sessions`
- دوال RPC الخاصة بالداش بورد

### 2) افتح مشروع الداش بورد

من التيرمنال داخل جذر المشروع:

```bash
cd admin-dashboard
npm install
npm run dev
```

ثم افتح:

```txt
http://localhost:5173
```

### 3) تسجيل الدخول

استخدم حساب مدير موجود في جدول `app_security` بشرط أن يكون:

```txt
role = admin
```

أو:

```txt
role = super_admin
```

نفس اسم المستخدم وكلمة المرور / PIN التي تستخدمها في التطبيق.

## ملاحظة مهمة

التطبيق الأصلي لم يكن يحتوي على جدول اشتراكات جاهز، لذلك أضفت جداول اشتراكات ومدفوعات جديدة. بعد تشغيل SQL، ستظهر أسماء المستخدمين الحقيقية فورًا من قاعدة البيانات، أما الاشتراكات فستظهر بعد إضافتها من لوحة التحكم أو إدخالها في الجداول الجديدة.


## الخط المستخدم

تم ضبط واجهة الداش بورد لاستخدام خط **Roboto** من Google Fonts عبر ملف `index.html`، مع تطبيقه في `src/styles.css`.

## تحديث حركة الحوالات المالية

تمت إضافة صفحة جديدة باسم **حركة الحوالات** داخل لوحة التحكم، وتقرأ البيانات الحقيقية من جدول التطبيق الحالي:

```txt
account_movements
```

تعرض الصفحة:

- إجمالي الحوالات والحركات المالية.
- الحوالات الله والعليه.
- التحويلات من عميل إلى عميل.
- التحويلات من المحل إلى عميل والعكس.
- الحوالات المعلقة والمعتمدة والمرفوضة.
- اسم المرسل والمستفيد.
- صاحب الحساب / المستخدم المرتبط بالحركة.
- رقم الحركة ورقم الحوالة والمبلغ والعملة والتاريخ.

بعد نسخ التحديث، شغّل ملف SQL الإضافي التالي مرة واحدة في Supabase:

```txt
supabase/migrations/20260501010000_admin_dashboard_transfer_movements.sql
```

إذا كان ملف SQL الأساسي وملف إصلاح `digest` قد تم تشغيلهما سابقًا فلا تحتاج لإعادتهما، فقط شغّل ملف حركة الحوالات الجديد.
